# Глава 1 — программная карта переходов и зависимостей

**Текущее состояние:** S00–S04 основаны на сценарии v0.1; S05–S08 — проходимая предложенная версия, не утверждённая командой. Карта tldraw остаётся внешним источником для визуальной сверки. При расхождении с утверждённым сценарием приоритет — сценарий.

## Работа с инвестициями

- Источник данных: `data.js`, импортирован из матрицы Google Sheets A1:Q14.
- Сумма рассчитывается только из выбранных уникальных кодов A–M.
- Перерасход разрешён для эксперимента с вариантами, но блокирует отправку.
- Риск и соответствие цели выводятся качественно: прямые, условные и спорные связи. Это **предварительное правило, требующее утверждения**.
- L/M: 0 в инвестиционном бюджете, но не 0 фактических затрат.
- Примеры значимых конфликтов: F+L, B+I, D+E, K+M.
- Сцена S06 не предполагает доказанную причину очереди. Различные инвестиции вызывают различные пояснения, но без произвольных численных бонусов.
- S07 даёт три сценарных решения с различными рисками, итог S08 учитывает портфель и второе решение.

## Что синхронизировать при изменениях

1. Утверждённый сценарий Google Docs.
2. Рабочую матрицу инвестиций Google Sheets.
3. **Единственную** действующую карту tldraw (не создавать новую страницу).
4. `scenario.js` — тексты и действия; `data.js` — инициативы; `logic.js` — проверки и последствия.
5. `app.js` — отображение и переходы.
6. `tests/smoke.test.js`, `docs/QA.md` и сведения для конкурсной защиты.

Ссылки на источники см. в корне репозитория, `README.md`.
