Для `andrey_neutral.png`, `marina_neutral.png` и дополнительных эмоций пока нет подключений в коде. Сначала утвердить образ и композицию. Не выдавать перечисленные изображения за готовые: сейчас в GitHub только папки-заготовки.

**Формат:** фон WebP, соотношение сторон 16:9; портрет — PNG с прозрачностью. После подключения проверить фактическое отображение на ноутбуке. Текст отчётов, инвестиционные суммы и кнопки хранить в HTML, не внутри картинки. Если ресурса нет, игра должна оставаться читаемой.

**Перед передачей Мише:** укажите точное имя, сцену, статус согласования, источник изображения и заменяет ли оно существующее. Не переименовывайте уже используемые файлы без согласования.

**Осторожно:** кадры реального производства и условные изображения станков подлежат проверке на техническую правдоподобность.
