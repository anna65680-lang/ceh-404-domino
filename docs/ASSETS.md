# Как добавить изображения, ничего не сломав

**Начните с инвентаризации уже созданных изображений**. Утверждённые файлы и текущий рабочий экран пропуска не заменять автоматически. Здесь указаны ожидаемые имена для *этой новой GitHub-версии*.

Сейчас все эти изображения **отсутствуют**; папки содержат только служебные файлы `.gitkeep`. Игра должна отображать текст и карточки без них. При загрузке изображений программа подхватит их автоматически, без переписывания HTML/JavaScript.

## Как загрузить через сайт GitHub

1. Открыть приватный репозиторий `ceh-404-domino`.
2. Перейти в нужную папку `assets/backgrounds` или `assets/characters`.
3. Нажать **Add file → Upload files** и выбрать файлы (на телефоне пункт может быть под меню `…`).
4. Проверить **точные имена**, расширения и прозрачность портретов.
5. Нажать **Commit changes**. После этого файлы появятся в репозитории.
6. Скачать ZIP, открыть `index.html` и убедиться, что картинки не перекрывают диалоги и текст.

Подойдёт фон в WebP (рекомендуемое соотношение 16:9), портрет PNG с прозрачностью. Размер и композицию согласовать с Мишей. Если изображение в JPG, лучше переэкспортировать его в WebP; менять только расширение файла нельзя.

## Что не стоит делать

Не рисовать числовые показатели и диалоги внутри изображений: текст должен оставаться программным. Не создавать отдельные рендеры под каждый вопрос. Не утверждать, что изображение интегрировано, пока оно не подключено и не проверено в браузере. Проверяйте техническую достоверность промышленной сцены.
