# ЦЕХ 404: Эффект домино — стартовый репозиторий

**Статус на 07.11.2026:** создан новый автономный технический прототип S00–S04. Это **не** подтверждённая рабочая версия команды и **не** законченный План Б. Существующую стартовую страницу с пропуском нельзя заменять без сравнения и проверки.

## Как открыть игру

1. Скачать ZIP репозитория через зелёную кнопку **Code → Download ZIP**.
2. Распаковать архив.
3. Открыть файл **index.html** двойным щелчком в браузере.

Предполагается запуск без интернета, поскольку проект не использует внешние библиотеки. **Фактический браузерный тест и приёмка пока не подтверждены.**

## Что реализовано в коде

- **S00:** ввод имени, показ пропуска, переход к первому рабочему дню.
- **S01:** три вопроса Ирине в произвольном порядке.
- **S02:** производственный отчёт и три варианта предварительного вывода с ответами.
- **S03:** три профессиональные позиции в произвольном порядке.
- **S04:** карточки всех 13 мероприятий A–M; выбор/отмена, расчёт бюджета 100 млн, три инвестиционные цели, базовая проверка обязательных полей и ограничения бюджета.
- **S05:** честно обозначенная заглушка. **S05–S08 не реализованы.**
- **Не реализовано:** утверждённая экспертная оценка соответствия инвестиционной цели и портфеля, логика производственных последствий, межглавные переходы, автоматическое сохранение прогресса.

**Сценарные формулировки S01–S03 сокращены и требуют сверки** с утверждённым документом. Данные — условный учебный кейс, а не производственные нормативы.
