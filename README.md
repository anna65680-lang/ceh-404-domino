# ЦЕХ 404: Эффект домино

**Браузерная образовательная игра для студентов СПО машиностроительного и производственного профиля.** Управленческие решения, производственные ограничения, инвестиции и реальные профессиональные компромиссы.

**Состояние на 07.11.2026:** **игровой маршрут S00–S08 запрограммирован** в новом репозитории. S00–S04 построены по согласованному сценарию; **S05–S08 — проходимый, но НЕ УТВЕРЖДЁННЫЙ проектный вариант**, написанный для проверки игровой механики. Не объявлять игру принятой: необходимы проверка в браузере, доработка графики, согласование последствий и интеграция уже работающей посадочной страницы команды.

## 🚀 Как запустить игру (без установки программ)

1. Откройте этот репозиторий в GitHub.
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Распакуйте архив.
4. Дважды нажмите на файл **index.html** — игра откроется в браузере.

Интернет для работы локальной игры не требуется. **Это предназначенный способ запуска; реальный браузерный тест командой ещё не подтверждён.**

## 🎨 Как подставить изображения

Созданы папки **`assets/backgrounds`** и **`assets/characters`**. Изображения не загружены. Код ожидает конкретные имена; после добавления правильных файлов фоны и портреты появятся без изменения программного кода. Читайте **[инструкцию по изображениям](docs/ASSETS.md)**.

## 🧱 Код и единое состояние

| Файл | За что отвечает |
|---|---|
| `index.html` | Страница запуска |
| `style.css` | Общий визуальный стиль и адаптация под экран |
| `data.js` | 13 инициатив и параметры **из Google Sheets** |
| `scenario.js` | Тексты, персонажи, сцены S00–S08 и метки утверждения |
| `logic.js` | Состояние, бюджет, условные связи и последствия |
| `app.js` | Рендеринг сцены, кнопки и переходы |
| `tests/smoke.test.js` | Автоматические логические проверки |

Прогресс хранится только в **локальном хранилище этого браузера**. Если на общем компьютере нежелательно оставлять введённое имя, после показа нажмите «Начать заново» и при необходимости очистите данные сайта.

## ✅ Что проверено, а что нет

**Проверено:** файлы и JavaScript прочитаны из GitHub, сквозной маршрут в модели DOM прошёл **25 из 25 логических проверок**, сопоставлены суммы инициатив A–M.

**НЕ проверено:** полноценный запуск в реальном браузере с графикой, удобство на ноутбуке/телефоне, согласованность черновых S05–S08, техническая достоверность всех учебных исходных данных, интеграция существующей рабочей S00, конкурсная приёмка.
